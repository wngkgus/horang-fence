# 호랭이휀스 홈페이지

## 바로 확인하는 방법
1. 이 폴더에서 `index.html` 파일을 더블클릭하세요.
2. 인터넷 브라우저에서 홈페이지가 열립니다.

## 무료로 공개하는 가장 쉬운 방법
### Cloudflare Pages
1. GitHub에 이 폴더를 올립니다.
2. Cloudflare Pages에서 GitHub 저장소를 연결합니다.
3. Framework preset은 `None`으로 선택합니다.
4. Build command는 비워두고, output directory는 `/`로 설정합니다.
5. Deploy를 누르면 `이름.pages.dev` 주소가 생깁니다.
